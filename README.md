## Project Description

This Java project implements an Employee Management System based on a UML class diagram. It demonstrates object-oriented programming concepts:

- An abstract `Employee` parent class.
- `CommissionEmployee`, `MonthlyEmployee`, and `HourlyEmployee` subclasses.
- A `Gender` enum.
- A `Department` class that manages employees.
- Salary calculation, employee searching, and total department payroll.

## How to Run

### Option 1: Online Java Compiler

1. Open an online Java compiler that supports Java 8 or later.
2. Copy the contents of `Main.java` into the editor.
3. Ensure the main class is named `Main`.
4. Click **Run**.

### Option 2: Run Locally

1. Install a JDK (Java 8 or later).
2. Open a terminal in the folder containing `Main.java`.
3. Compile the program:

   ```bash
   javac Main.java
   ```

4. Run it:

   ```bash
   java Main
   ```

The program prints employee information and salaries, the department's total payroll, an employee search result, and an additional vacation calculation.
